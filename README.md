## 🎮 what I'm making

### [Zelda-sandbox](https://github.com/Trojanhammer/Zelda-sandbox)
A 2D sandbox for Breath of the Wild and Tears of the Kingdom mechanics, in C++17 and SDL2 with no engine and no physics library. Each mechanic is built and tested on its own first: Recall, Updraft, Magnesis and Stasis, on a shared physics base class, with a state-machine monster AI. I write the gameplay and physics by hand. AI helped with the SDL2 drawing, the gamepad input and code review, and the README says so. It isn't complete, but I'm happy with how far it got.

### [Zelda-Link.cpp](https://github.com/Trojanhammer/Zelda-Link.cpp)
A turn based Zelda duel in C++ and SDL2 with no engine. I wanted to figure out game physics on my own so I write all the game code by hand. The automated testing tools are the only AI part and the README says so.
